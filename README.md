# Proyecto Final RCD 2026-2 — Equipo 5 (`sslmjp.net`)

Diseño e implementación de una red empresarial en Cisco Packet Tracer 9.0.1:
- intranets de doble pila en Bogotá y Madrid;
- DMZ solo IPv6;
- Internet solo IPv4 con EIGRP + OSPF;
- túneles 6in4/GRE con VPN IPsec;
- SNMP restringido;
- la solución **Employee Tracker** con sockets TCP y tablero web.

**Integrantes:** Samuel Santiago Blanco Galeano · Lizeth Marianyi Zamora Gomez · Juan Pablo Mora Silva
